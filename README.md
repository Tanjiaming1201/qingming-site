# 清明上河 · 一日千年

一个以宋代汴京沿河街市为主题的交互长卷学习作品。打开网站，选择水磨、茶市、虹桥或城门，沿河行走、饮茶、喂鸟、逛集市，或乘船渡河。

本作品参考 [xianxie6/qingming-riverside](https://github.com/xianxie6/qingming-riverside) 的体验与交互构思，使用原生 JavaScript、Canvas 2D 和独立编写的场景逻辑重新实现。

## 可以体验什么

- 方向键或 A、D 行走，点击街道前往，拖动画卷浏览；滚轮平移，双击放大细节。
- 到茶铺看添茶、杯汽，端杯品茶或再添一盏；在桥头撒谷粒，观察雀鸟飞来、落地啄食和飞离。
- 在城门货市挑选春茶、瓷器与绢布，向店家询价、打听虹桥。
- 招船后沿栈桥登船、沿河航行，再沿栈桥走回岸上。
- 切换温暖夜景与清明时雨，夜里看灯火与河面倒影，雨中看路人撑伞。
- 参与虹桥过船：按住落桅，再牵绳过桥，完成后保存一幅画稿。

按 E 可在附近互动；空格暂停或继续，Esc 结束当前互动或停止行走。手机也可以使用画面按钮、拖动和双指缩放。

互动会有轻柔的杯响、倒水声、鸟鸣和询问确认音。环境弦乐默认关闭，声音按钮可开启环境声音，再次点击可静音全部声音。

## 素材与说明

街市背景与人物素材使用 AI 生成，并为长卷场景和动画做了适配。背景是宋代风物的艺术再创作，并非《清明上河图》原画扫描。天气、雨伞、船只、茶桌、雀鸟、灯火和交互由程序绘制。店家对白和货价为学习作品中的情境演绎。

这是参考原项目独立实现的学习与展示作品，保留原项目链接用于说明灵感来源。网站采用静态文件发布，电脑和手机使用支持 JavaScript 的现代浏览器即可访问。
